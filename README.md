# Student Task Manager

A frontend-first student task manager with backend project trial files included.

## Features
- Responsive landing page, login, register, dashboard, tasks, profile, and settings pages
- Task CRUD operations with local storage persistence
- Search, category filtering, priority filtering, and due-date sorting
- Dark/light mode toggle and polished UI components
- Includes backend server and route files for future backend integration

## Run locally
Open `index.html` in your browser or use a simple local server such as:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
